# 우리 결혼 준비

예비 신혼부부를 위한 결혼 준비 플래너입니다. <https://cooperkang.github.io/wedding/>

처음 화면에서 예식일, 하객 수, 지역, 예산 성향(형식만 갖추는 저예산 / 저예산이지만 하고 싶은 건 / 무난하게 / 호텔·프리미엄), 준비 스타일(맡기기 / 로망 있음 / 직접 발품), 원하는 예식 형태, 스드메 방식, 예식장에서 중요한 것(주차·식사·교통 등)을 고르면 모든 화면이 그 커플에 맞춰집니다. 입력값은 브라우저(localStorage)에만 저장됩니다.

- **처음(진단)**: D-day, 지금 할 일 3가지, 준비 스타일별 준비 순서(플래너형은 플래너 비교부터, 로망형은 예식장부터, 발품형은 직접 투어부터), 어울리는 예식장 유형, 예산 대략값
- **타임라인**: 꼭 따를 필요 없는 가이드라는 안내, 10개월 이상 전부터 예식 이후까지 단계별 할 일, "늦어도 몇 개월 전" 표시와 그 이유(뒤에 이어지는 일까지 생각한 여유, 안 할 때의 최소 시점), 가장 바쁜 시기(1~2개월 전) 강조, 예식일 기준 실제 날짜, 밀린 일 알림, 촉박할 때 압축 준비법
- **예식장**: 원하는 날짜·시간·홀을 잡으려면 언제부터 연락할지(유형별 보편 시점·인기 시간대, 우리 예식일로 계산), 유형별 장단점과 추천, 참가격 시세, 우선순위가 위로 올라오는 투어 체크리스트, 계약서 확인 항목, 박람회 사용법, 지역 예식장 목록(별점·리뷰·주차·블로그 후기 신호, 좋았던 점·아쉬운 점 해시태그)
- **스드메**: 토탈 스튜디오 / 플래너 패키지 / 직접 발품 비교, 기본가에 안 들어가는 돈 체크리스트, 업체 담기 → 하루 방문 순서 최적화와 시각표, 구간별 카카오맵 길찾기
- **신혼여행**: 여행사 집계 인기 여행지(빅5), 여행지 11곳의 1~12월 추천 시기 표와 흔한 일정(박수), 여행지별 예상 총액, 항목별 예산(항공·숙소·식비·투어·교통·선물·보험·그 밖, 추정치를 고쳐 쓸 수 있음)과 선물 목록, 예산 장부로 보내기, 여행사·자유여행 견적 비교표(1박당 가격, 빠진 항목)
- **예물·청첩장**: 예물·예단, 한복, 청첩장, 본식 스냅, 당일 역할, 혼인신고 시점
- **지원 정책**: 결혼 세액공제, 혼인 증여재산 공제, 신혼부부 대출·특별공급, 공공예식장, 가임력 검사, 결혼서비스 가격표시제·표준계약서, 주간 뉴스
- **예산 장부**: 지역 시세를 반영한 예산 프리셋(최소·실속·표준·호화), 스프레드시트처럼 한 표에서 고치는 장부(결제 한 건이 한 줄: 계약금·중도금·잔금, 낼 날, 낸 사람, CSV 내보내기), 양가 지원금, 낸 사람별 합계, 다가오는 지급
- **기록·공유**: 읽기 전용 공유 링크(장부를 압축해 주소에 담음, 금액 숨김 가능), JSON 내보내기·가져오기, 인쇄용 기록집

## 개발

```sh
npm install
npm run dev      # http://localhost:5173
npm test
npm run build
npm run crawl    # public/data/*.json 다시 모으기(약 25분)
```

## 데이터 수집

`crawler/`는 의존성 없는 Node 스크립트로, GitHub Actions(`.github/workflows/crawl.yml`)가 매주 월요일 새벽에 돌려 `public/data/`에 커밋합니다. API 키 없이 공개 검색 결과만 읽습니다.

| 파일 | 출처 | 내용 |
|---|---|---|
| `vendors.json` | 카카오맵 검색 | 29개 지역 × 웨딩홀·호텔·스몰웨딩·스튜디오·드레스·메이크업·플래너·한복·예물. 이름, 주소, 좌표, 별점, 리뷰 수, 주차, 전화, 홈페이지 |
| `reviews.json` | 네이버 블로그 검색(막히면 다음 블로그 검색) | 업체별 "후기" 글 수, 제목·미리보기의 좋은 말/아쉬운 말/협찬 표시 개수, 해시태그별 글 수(#식사맛집, #주차불편 등), 대표 글 3개. 한 번에 300곳씩 오래된 순으로 갱신 |
| `news.json` | 구글 뉴스 RSS | 신혼부부 지원·결혼 세액공제 등 최근 60일 기사 30건 |
| `meta.json` | | 소스별 수집일과 성공 여부 |

소스마다 따로 실패할 수 있고, 실패하면 지난번 파일을 그대로 둡니다. 파서는 `crawler/fixtures/`에 저장한 실제 응답으로 테스트합니다(`crawler/parse.test.mjs`). 지역을 바꿀 때는 `crawler/config.mjs`와 `src/data/regions.ts`를 같이 고칩니다(테스트가 확인).

## 숫자 고치기

| 무엇 | 어디 | 기준 |
|---|---|---|
| 정책(세액공제, 대출, 특별공급 등) | `src/data/policy.ts`, `POLICY_AS_OF` | 2026년 10월 21일, 각 카드에 공식 링크 |
| 예산 프리셋·시세 | `src/data/budget.ts` | 한국소비자원 참가격 결혼서비스(2026년 8월 계약), 듀오 2026 결혼비용 보고서 |
| 타임라인 할 일 | `src/data/timeline.ts` | 업계 통상 기준 |
| 신혼여행지·시기·예상 비용 | `src/data/honeymoon.ts` | 순위는 팜투어·허니문리조트 2025 집계, 평균은 듀오 2026(763만원), 여행지별 비용은 2026년 대략값(추정) |

업체별 가격은 공개되지 않아 수집하지 않습니다. 결과는 참고용입니다.
